## 🛠️ Tech Stack & Key Features
- **Frontend Core:** Semantic HTML5, Vanilla CSS3 (Custom Glassmorphism Design System, Responsive Bento Grid, Dark Mode).
- **Interactive Particle Background:** Hardware-accelerated HTML5 Canvas with proximity constellation lines and cursor repulsion.
- **Interactive AI Labs:**
  1. **RAG Semantic Search Simulator:** Simulates cosine vector similarity retrieval over FAISS embeddings.
  2. **DiabetaNet & SHAP Attribution Tool:** Real-time clinical parameter adjustment with live soft-voting probability and SHAP bar charts.
  3. **AeroHeal PPO Telemetry Simulator:** Real-time 4D server telemetry monitoring with autonomous self-healing policy actions.
- **Interactive Terminal CLI (`zsh`):** Interactive terminal shell supporting `help`, `skills`, `projects`, `certs`, `contact`, `cat resume.txt`, and history traversal.
- **Resume Modal & Print Engine:** Pixel-perfect printable and downloadable CV viewer.
- **SEO & Performance:** Optimized for 100/100 Lighthouse performance, zero heavy dependencies, fast initial load.

## 📦 Local Development

To run locally:
```bash
npx serve .
# or
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.

---

## 🌐 Deploy to Vercel

To deploy to your Vercel account (`https://vercel.com/k7sarathi-4798s-projects`):

```bash
# 1. Login to your Vercel account
vercel login

# 2. Deploy directly to production
vercel --prod
```

Or initialize Git and push to GitHub, then import into Vercel:
```bash
git init
git add .
git commit -m "feat: initial release of K. Parthasarathi portfolio"
```
